> **幸運物象徵**：🍎 **紅蘋果**（象徵蘋安、圓滿與收穫）與 🐻 **焦糖小熊**（象徵溫暖、守護與治癒）

---

## 🎨 一、設計規劃與視覺美學

1. **視覺風格**：
   - **Low-Poly（低面數）3D 美學**：採用平面著色（Flat Shading）幾何形體，搭配溫暖柔和的焦糖棕、奶油米白、紅蘋果色與森林綠，營造如獨立繪本遊戲般的精緻療癒質感。
   - **光影與氛圍**：主定向光投射柔和接觸陰影，輔以粉橘側緣光（Rim Light）與暖調環境光，並有緩緩漂浮的幸運微光金粉粒子。
   - **UI 介面**：採用現代毛玻璃設計（Glassmorphism），搭配圓潤可愛的字體（Fredoka / Outfit / Noto Sans TC），兼具極簡與質感。

## 🕹️ 二、互動機制與動態效果

### 1. 滑鼠懸停（Hover）動態效果
- **目光跟隨**：小熊頭部與目光會隨著使用者滑鼠游標的位置進行平滑插值（Lerp）跟隨轉動。
- **物件感知反應**：
  - 當游標移至**蘋果**上方：游標變為指針手勢，蘋果微微旋轉並跳動，跳出浮動提示標籤「*多汁脆甜的幸運蘋果！點我餵小熊*」。
  - 當游標移至**小熊**上方：小熊兩隻圓耳朵會輕快抖動，跳出「*好想吃蘋果喔〜*」心情提示。
- **音效回饋**：懸停物件時觸發清脆細微的合成音效。

### 2. 點擊（Click）餵食核心動畫（GSAP 時間軸控制）
使用者點擊畫面中的**蘋果**、**小熊**或點擊下方「**餵小熊吃蘋果！**」按鈕，將依序觸發多段流暢連貫的 3D 動畫：
1. **驚喜注目**：小熊頭部迅速轉向蘋果，耳朵開心地豎起微動。
2. **伸手拿取**：小熊右手臂關節順暢前伸，蘋果自木樁浮起並平滑飛入掌心。
3. **送入口中**：手臂帶動蘋果抬升至嘴邊，小熊頭部湊近。
4. **大口咀嚼**：
   - 連續兩段點頭咀嚼動作。
   - 伴隨 Web Audio API 合成的「喀嚓脆響」咀嚼音效。
   - 蘋果體積遞減（100% → 75% → 35% → 0% 吃完消失）。
5. **歡呼慶祝**：
   - 小熊開心地雙手舉高歡呼、身體蹦跳兩下。
   - 播放歡樂和弦音效，並在畫面上迸發七彩幸運彩帶（Confetti）。
   - 幸運能量條充填、蘋果享用計數器 +1。
6. **新生果實**：一顆全新的飽滿紅蘋果從天而降，帶有彈性形變（Bounce & Squash）穩穩落回木樁上，等待下一次互動。

### 3. 視角與擴充互動
- **360° 軌道檢視**：支援滑鼠左鍵拖曳 360 度環視 3D 低面數小熊與場景，支援縮放與視角限制防穿幫。
- **智能防誤觸**：精確區分滑鼠「旋轉拖曳」與「點擊動作」，旋轉視角時不會誤觸吃蘋果動畫。
- **今日幸運籤（Fortune Modal）**：點擊「抽取今日幸運籤」可抽取專屬幸運密語與幸運色。
- **零外部音訊依賴**：所有音效（咀嚼脆聲、彈跳、歡呼、懸停）均以瀏覽器原生 Web Audio API 即時合成，免除外部音訊載入延遲或 404 問題。
